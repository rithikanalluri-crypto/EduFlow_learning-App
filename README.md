# EduFlow – Learning App

## About the Project
EduFlow is a student-friendly learning application designed to help students access courses, learn lessons, take quizzes, and track their learning progress.

## Features
- Student Login and Registration
- Course List
- Learning Lessons
- Multiple-Choice Quizzes
- Quiz Results
- Logout

## Technologies Used
- HTML
- CSS
- JavaScript

## Objective
To provide a simple and interactive platform for students to learn and practice online.

## Future Enhancements
- Student progress tracking
- More courses and quizzes
- Improved user interface
